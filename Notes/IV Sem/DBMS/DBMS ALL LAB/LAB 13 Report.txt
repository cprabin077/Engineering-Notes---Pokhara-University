Stored Procedure:
---------------------------------------------------------------------
Syntax:
 Create procedure proc_name([paramater])
 
Begin
    execution

End

Example:
 	delimiter $$

	 Create procedure sp_emp_info()
         begin
           select * from employee;
         End

         $$

To execute procedure:
----------------------------------------------------------------------------------
syntax : 
  Call procedure_name([argument list])

Eg:
   Call sp_emp_info();

delimiter $$
	create procedure sp_emp(In emp_id int, OUT emp_name varchar(20))
    	begin
    	 select ename into emp_name from employee
    	where eno = emp_id;
   	end
      $$ 

To call:
 call sp_emp(7,@emp_name);
